# Rambler Mail OTP Reader

Программа для автоматического получения кодов подтверждения (OTP) из писем на почтовых ящиках Rambler.ru.

## Возможности

- Поддержка нескольких аккаунтов
- Автоматический режим — копирует код из последнего письма (сохраняется между запусками)
- Ручной режим — выбор письма из списка за последние 24 часа
- Пагинация списка писем (по 10 на странице)
- Автоматическое извлечение кода из текста письма
- Если код не найден — открывает письмо в браузере
- Обновление списка писем без выхода из аккаунта

## Установка

1. Установите Python 3.8+
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Отредактируйте `creditials.txt` — укажите свои аккаунты в формате `email:password` (каждый с новой строки)

## Использование

```bash
python ramb.py
```

### Режимы

- **Обычный режим**: выберите аккаунт, затем письмо из списка
- **Авто-режим (A)**: переключается в главном меню. В этом режиме код из последнего письма сразу копируется в буфер обмена

### Управление в списке писем

- `[N]` / `[P]` — листать страницы
- `[R]` — обновить список писем
- `[A]` — авто-режим (последнее письмо)
- `[0]` — назад

## Зависимости

- `imap-tools` — работа с IMAP
- `pyperclip` — работа с буфером обмена

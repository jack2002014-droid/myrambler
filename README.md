# Rambler Mail OTP Reader 1.0

Новая папка, старый проект не тронут. Логика сохранена, добавлено удобство для пачек по 10 почт.

## Что нового против старого

- Список аккаунтов: страницы по 10, нумерация 1–10 на каждой странице.
- Поиск: введи часть почты (`gre12` или `/gre12`) вместо номера.
- `Последние:` сверху — 3 ящика, где только что был.
- Мышь: наведи на почту — строка подсветится, клик ЛКМ — зайти и скопировать код из последнего письма автоматом. Так же клик по письму в списке.
- После кода: `[N] следующий аккаунт` — идешь по пачке 1→2→...→10 без возврата в меню.
- Список писем: страницы по 10, нумерация 1–10 на каждой, видно отправителя, `✓` где есть код.
- Страница не сбрасывается: выбрал письмо на 2-й странице или обновил список — остаешься на ней, пока сам не перелистнешь (Z/X).
- `W — ждать новое`: опрос каждые 5 сек, как только письмо пришло — код сразу в буфере + звук. Не надо жать R.
- Коды точнее: игнор годов 1930–2035, приоритет 5–6 знакам, показ запасных вариантов `[2/N]`.
- Быстрее: тянем только 30 последних писем (`reverse + limit`), чистим `message_*.html`, `logout()` всегда.
- Файл паролей: `credentials.txt` (новый) или `creditials.txt` (старый, работает).
- Хоткеи только внутри консоли — конфликтов с другими программами нет. Глобальных хуков нет специально.

## Управление

Меню аккаунтов: номер 1–10 на текущей странице / клик мышью / `/текст` поиск / `Z/X` страницы / `C` очистить поиск / `A` авто / `S` звук / `0` выход.

Внутри ящика: номер 1–10 / клик мышью / `A` последнее / `W` ждать новое / `R` обновить / `Q` след. аккаунт / `Z/X` страницы / `0` назад.

Авто-режим (`A` в меню): как раньше — сразу копирует код из последнего письма. После — `N` для следующего по списку.

## Запуск

Двойной клик по `start.bat` (или `ramb.exe`) — откроется консоль, там работаешь.
Если exe нет — батник сам запустит `python ramb.py`.

Вручную:
```bash
pip install -r requirements.txt
python ramb.py
```

Свои почты положи в `credentials.txt` (формат `email:password`, по одной на строке).
Пересобрать exe после правок: `python -m PyInstaller --onefile --console --name ramb --noconfirm ramb.py`, потом перенести `dist\ramb.exe` в корень.
